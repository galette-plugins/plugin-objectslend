# Galette ObjectsLend plugin

[![GitHub license](https://img.shields.io/github/license/galette-plugins/plugin-objectslend)](https://github.com/galette-plugins/plugin-objectslend/blob/master/COPYING)
[![Maintained by the Galette core team](https://img.shields.io/badge/maintained_by-Galette_core_team-ffb619?style=for-the-badge&logo=php&logoColor=white)](https://galette.eu)

### English

A [Galette](https://galette.eu) plugin to manage objects, lends and rents.

This plugin is developed and maintained by the **Galette core team**, along with Galette itself — unlike most of the plugins hosted in this organization, which are community-maintained.

* website: https://galette-plugins.github.io/plugin-objectslend/
* bugs and features: https://bugs.galette.eu/projects/galette-plugin-objectslend
* mailing lists:
  * users: https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * developers: https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation: https://galette-plugins.github.io/plugin-objectslend/documentation.html

To use Galette ObjectsLend plugin, you'll need a reliable Galette version, and of course the plugin itself by either:

* download latest version available from the [releases page](https://github.com/galette-plugins/plugin-objectslend/releases)
* use [Galette ObjectsLend plugin source code from repository](https://github.com/galette-plugins/plugin-objectslend), this solution requires some technical skills

### Français

Un plugin [Galette](https://galette.eu) pour gérer objets, prêts et locations.

Ce plugin est développé et maintenu par l'**équipe Galette**, comme Galette lui-même — contrairement à la plupart des plugins hébergés dans cette organisation, qui sont maintenus par la communauté.

* site web : https://galette-plugins.github.io/plugin-objectslend/
* bogues et fonctionnalités : https://bugs.galette.eu/projects/galette-plugin-objectslend
* listes de diffusion :
  * utilisateurs : https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * développeurs : https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation : https://galette-plugins.github.io/plugin-objectslend/fr/documentation.html

Pour utiliser le plugin ObjectsLend pour Galette, vous aurez besoin d'une version adéquate de Galette, ainsi que du plugin lui-même :

* télécharger la dernière version depuis la [page des versions](https://github.com/galette-plugins/plugin-objectslend/releases)
* utiliser [le code source du plugin ObjectsLend pour Galette depuis le dépôt](https://github.com/galette-plugins/plugin-objectslend), cette solution requiert quelques compétences techniques
